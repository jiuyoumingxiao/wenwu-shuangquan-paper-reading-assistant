# 没文没武论文阅读助手 · 发布版

研究生组会场景的论文阅读汇报桌面助手。本仓库为**发布仓库**，程序安装包存放在 [Releases](../../releases) 中，不放入 git 历史。

源码仓库：https://github.com/jiuyoumingxiao/paper-workbench

## 当前版本：v0.0.1

| 文件 | 说明 |
|---|---|
| `没文没武论文阅读助手-Portable-0.0.1.exe` | **免安装便携版**，双击即用，适合拷给同学 |
| `没文没武论文阅读助手-Setup-0.0.1.exe` | **安装版**，向导式安装，自动创建桌面/开始菜单快捷方式 |

## 使用说明

1. 首次打开若弹出蓝色「Windows 已保护你的电脑」提示：点击 **更多信息 → 仍要运行**（应用未做代码签名，属正常现象，非病毒）
2. 打开后点右上角 **⚙ 设置 → AI 接入**，填入你自己的模型 API Key（兼容 OpenAI 协议：阿里千问 / DeepSeek / Kimi / GLM / MiniMax 等），测试连通并启用
3. 把论文 PDF 拖进窗口即可入库

## 数据说明

- 阅读记录、任务清单、素材等数据保存在**本机** `%APPDATA%\paper-workbench\`，不会上传网络
- API Key 同样只存本机；卸载重装数据仍在
- 从便携版换安装版（或反过来），数据互通，无需迁移
