# 没文没武论文阅读助手 · 发布仓库

研究生组会场景的论文阅读汇报桌面助手。本仓库存放**打包好的 Windows 程序**，源码见 👉 https://github.com/jiuyoumingxiao/paper-workbench

## 当前版本：v0.1.0（2026-10）

程序在 [`app/`](app) 目录，两种方式获取：

| 文件 | 用法 |
|---|---|
| `没文没武论文阅读助手-Portable-0.1.0.exe` | **免安装便携版**：右键 View raw / 下载后双击即用，适合直接发给同学 |
| `没文没武论文阅读助手-Setup-0.1.0.exe` | **安装版**：向导安装，自动创建桌面/开始菜单快捷方式 |

> 下载单个 exe 最方便的方式：进入 `app` 目录 → 点中文件 → **Code/Download** 按钮，或用命令行 `git clone --depth 1` 本仓库。

## v0.1.0 功能一览

- 📥 拖 PDF 入库：arXiv 元数据自动补全、首页缩略图、标签、五态看板、搜索筛选
- 🧠 阅读状态：章节 + 页码 checkpoint、历史时间线、恢复视图一键跳回上次页
- 📖 内置阅读器：翻页缩放、分屏边读边问、✂ 框选截取存素材、框选翻译（实验）
- 🗂 右侧栏：AI 任务清单 / 素材库（标注、页码回溯、一键复制进 PPT）/ 待解决问题
- 🎓 汇报助手：快速回忆、思路精炼、提问预演（支持"老师提问画像"仿写）、PPT 大纲（自由/预设骨架）
- 🎨 个性化：纸本学术 / 极简黑白双主题、光标皮肤、界面缩放

## 使用说明

1. 首次运行弹蓝色「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**（未做代码签名，属正常）
2. 打开后点右上角 **⚙ 设置 → AI 接入**，填入自己的模型 API Key（兼容 OpenAI 协议），测试连通并启用
3. 拖入论文 PDF 开始使用

## 数据与隐私

- 阅读记录、素材、API Key 全部保存在**本机** `%APPDATA%\paper-workbench\`，不随仓库分发，不会上传网络
- 从旧版本升级直接覆盖安装即可，数据保留
