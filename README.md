## 使用三步

1. 首次运行若弹蓝色「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**（未做代码签名，属正常现象）
2. 打开后右上角 **⚙ 设置 → AI 接入**：填入你自己的模型 API Key（兼容 OpenAI 协议：千问/DeepSeek/Kimi/GLM/MiniMax 等），测试连通并启用
3. 拖入论文 PDF，开始使用

## 功能速览

- 📥 拖 PDF 入库：arXiv 元数据自动补全、首页缩略图、标签、五态看板、搜索/标签筛选
- 🧠 阅读状态：章节+页码 checkpoint、历史时间线、恢复视图一键跳回上次页
- 📖 内置阅读器：翻页缩放、分屏边读边问、✂ 框选截取存素材、框选翻译（实验）
- 🗂 右侧栏：AI 任务清单 / 素材库（标注、页码回溯、一键复制进 PPT）/ 待解决问题
- 🎓 汇报助手：快速回忆、思路精炼、提问预演（可模仿"老师提问风格"）、PPT 大纲（自由/预设骨架）
- 🎨 个性化：纸本学术/极简黑白双主题、8 款光标皮肤、界面缩放

## 数据与隐私

- 阅读记录、素材、API Key 全部保存在**本机** `%APPDATA%\paper-workbench\`，不随程序分发、不会上传网络
- 版本升级：解压覆盖 / 重新安装即可，数据自动保留
