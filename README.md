## 使用说明

1. 首次运行若弹蓝色「Windows 已保护你的电脑」：点 **更多信息 → 仍要运行**（未做代码签名，属正常）
2. 打开后点右上角 **⚙ 设置 → AI 接入**，填入自己的模型 API Key（兼容 OpenAI 协议），测试连通并启用
3. 拖入论文 PDF 开始使用

## 数据与隐私

- 阅读记录、素材、API Key 全部保存在**本机** `%APPDATA%\paper-workbench\`，不会上传网络
- 解压覆盖即可升级，数据自动保留
- zip 分发版仅保留了中文/英文界面资源包（裁掉了其余 53 种语言的 Electron 本地化文件），程序功能无影响
